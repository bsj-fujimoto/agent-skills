# recap.json の形

`build.py` に渡す JSON。すべて日本語で書く。

```jsonc
{
  "title":    "ブラウザのタブに出る名前",
  "eyebrow":  "SESSION 80ee9307",          // 小さく上に出るラベル
  "headline": "AIと人間で「設計書」をまるごと1本つくった45時間",
  "subhead":  "1〜2文。何をしたセッションなのかを、前提知識ゼロの人に。",

  // 数字4つ。[値, ラベル] の順。値は短く（"864" "約45h"）
  "stats": [["70","やり取りの回数"], ["864","ツール実行"],
            ["11","別AIへの委譲"], ["約45h","かかった時間"]],

  // 進めた順の段階。5〜8個が読みやすい
  "phases": [{
    "id":     "P1",                        // turns から参照する。重複不可
    "name":   "設計書をつくる",              // 8文字前後。動詞で終える
    "color":  "#6366f1",                   // 段階ごとに変える
    "when":   "9/12 午前 ／ T1〜T5",        // いつ・どのターンか
    "what":   "既にある資料をかき集めて、抜けているところを見つける",  // 1文で要点
    "detail": "…具体的に何をしたか。2〜3文。数字を入れると効く"
  }],

  // 全体をつらぬく反復。無ければ null（枠ごと消える）
  "loop": {
    "title": "そして全体を貫いていたのは、この5歩のくり返し",
    "lead":  "上の段階のどこにいても、実際にやっていたことはこれでした。",
    "steps": [{"icon":"❓","title":"人が問いを投げる","desc":"「これで大丈夫？」"}]
  },

  "turns": [{
    "n":      1,                 // 元ログのターン番号。飛んでよい
    "ts":     "09-12 09:14",     // 表示用。短く
    "phase":  "P1",              // phases の id
    "user":   "人間が言ったこと。長ければ要約してよいが、口調は残す",
    "ai":     "AIが何をして何を返したか。1〜2文",
    "tools":  35,                // 省略可
    "agents": 3,                 // 省略可
    "pivot":  true               // 省略可。流れが変わった回だけ true
  }],

  "text": {
    "flowLead":     "図の下に出る1文",
    "timelineLead": "タイムラインの下に出る1文",
    "insight":      "黄色い枠。<b> と <br> が使える。ここだけHTML可",
    "footer":       "出典。<code> と <br> が使える"
  }
}
```

## 決まりごと

- `turns[].phase` は `phases[].id` に必ず存在すること（無いとビルドが止まる）
- `user` / `ai` はプレーンテキスト。タグを書いても表示されるだけ（エスケープされる）
- `insight` と `footer` だけは HTML として解釈される
- `</script` を含む本文を書いても安全（`build.py` が無害化する）
