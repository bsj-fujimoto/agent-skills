# eli5

そのトピックを**何も知らない人**に説明するつもりで、**大きな図と少ない言葉**だけで構成した
HTML ページを作る。文章で埋めない。図で分かるなら文は要らない。

引数があればそれがトピック。無ければ直前のやり取りから取る。

## 出力ルール（必須）

**ここまでやって「完了」。** 毎回ユーザーに言わせない。

1. **ローカルファイルとして生成する。** Artifact として公開しない
2. 保存先はスクラッチパッドディレクトリ（システムプロンプトに示されるセッション用の一時ディレクトリ）。
   ユーザーが保存場所を指定したらそちらに従う
3. ファイル名は `eli5-<トピックのスラッグ>.html`
4. **[[commentable-html]] を適用する**（ローカル HTML の既定。そのスキルの assets を
   `<style>` `<script>` に直接埋め込み、主要な要素に `data-src` を振る）
5. **書き出したらブラウザで開く**: `open <絶対パス>`
6. 最後に**絶対パスと、開いたこと**を伝える

## 中身の作り方

- **数字は大きく出す。** 一番言いたい数を最初に、他より明らかに大きく
- **図は SVG をインラインで書く。** 外部ライブラリを読み込まない（`file://` で開くため）
- **図が主、文が従。** 段落を並べたくなったら、それは図にできないか先に考える
- **ライト／ダーク両対応。** `prefers-color-scheme` で色を切り替える
- **横幅 400px でも崩れないこと。** 表と図は `overflow-x:auto` の箱に入れる
- 事実と、そこから言えることを混ぜない。**推測は推測と書く**
