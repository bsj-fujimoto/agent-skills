# eli5

そのトピックを何も知らない人に説明するつもりで、大きな図と少ない言葉だけで構成した HTML ページを作る。

## 出力ルール（必須）

- **HTML は常にローカルファイルとして生成する。** Artifact として公開しない。
- 保存先はスクラッチパッドディレクトリ（システムプロンプトに示されるセッション用の一時ディレクトリ）。ユーザーが明示的に保存場所を指定した場合はそちらに従う。
- ファイル名は `eli5-<トピックのスラッグ>.html` のように内容が分かるものにする。
- **生成が完了したら必ずブラウザで開く**: `open <生成したHTMLの絶対パス>`
- 最後にユーザーへ、生成したファイルの絶対パスとブラウザで開いたことを伝える。

トピック: $ARGUMENTS
