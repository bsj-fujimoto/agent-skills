# Macのディスク調査

## 大原則

**読み取りしかしない。** 移動も削除も、こちらからは絶対にやらない。
成果物は「どれをどうすればいいか」が書かれたHTMLで、実行は本人が判断する。

レポートには毎回はっきり書く: **「まだ何も消していません」**

## 手順

### 1. スキャン

```bash
bash ~/.claude/skills/mac-disk-audit/scripts/scan.sh /tmp/scan.txt
```

読み取り専用・sudo なし。2〜5分かかる。終わったら全部読む。
特に **8章（シミュレータ取り残し検出）** と **9章（Android の依存確認）** は
そのまま判定材料になるので飛ばさない。

足りなければ個別に `du -sh` を足す。ただし:

- データボリューム全体は **`du -sh -x`**（`-x` 無しはマウントを二重計上する）
- `find / -size +300M` は返ってこない。`~/Downloads` `~/Desktop` に絞る

### 2. 仕分ける

`references/catalog.md` の表に当てはめる。判断に迷ったら `references/pitfalls.md`。

**サイズ順ではなく「作り直せるか」で4つの箱に入れる。**

1. 🗑️ 消してOK — 自動で作り直される。判断が要らない
2. 🔍 見てから消す — 「◯◯を使っていますか？」の**1問**に畳めるまで調べる
3. ☁️ クラウドへ — 実データ。上げてからローカルを空に
4. 🚫 さわらない — 壊れる・OS管理

「見てから消す」に入れるものは、**確認すべき一言を必ず書く**。
「SDK Manager から不要なものを外せます」では相手は動けない。
「Android エミュレータを使っていますか？ 使っていなければ AVD ごと 5.9GB 不要です」まで詰める。

裏取りの例（`pitfalls.md` 参照）:
- NDK → インストール済み版 vs プロジェクトの `ndkVersion` を突き合わせる
- system-images → AVD の `image.sysdir.1` が指しているか
- `.git` が重い → `git remote -v` があるならクラウド退避は不要、ローカル削除で足りる

### 3. レポートを書く

データを JSON にして、テンプレートに流す。

```bash
python3 ~/.claude/skills/mac-disk-audit/scripts/build-report.py \
  ~/Desktop/mac-disk-cleanup.data.json ~/Desktop/mac-disk-cleanup.html
```

JSON の形は `references/data-schema.md`。コメントレイヤーは自動で埋め込まれる。
**JSON も消さずに残す**（次回の差分に使う）。
**出力先は毎回同じパスにする**（2回目以降の上書き＝更新になり、打ったコメントも残る）。

書き方:

- **絵を大きく、字は少なく。** 専門用語はそのままにせず「下ごしらえデータ」「更新の残骸」と言い換える
- 各項目は「これは何か」1〜2文 → パス → コマンド。コマンドは**コピーできる形**で置く
- `highlight` には、その回いちばんの発見を1枚のSVG図にして置く（無ければ省略可）
- `steps` は「効果が大きく判断がかんたんな順」。サイズ順ではない
- 測定時刻をフッタに必ず書く（スキャン中も数字は動く）

### 4. 伝える

レポートのパスと、要点3行。最後にコメントの使い方を1行:

> 右下の「コメント」（または `C` キー）でピンを刺せます。JSONで書き出して貼ってもらえれば直します。

## 2回目以降（再スキャン）

前回のレポートと JSON が残っていれば、差分を出せる。

1. `scan.sh` をもう一度回す
2. 前回 JSON の `meta.freeGB` を今回の `meta.prevFreeGB` に、`usedGB` を `prevUsedGB` に入れる
   → ゲージが「前回」バーと「◯GB 空きました」を自動で描く
3. 消えていた項目を `done[]` に移す
4. 残っている項目は数字を測り直す。**前回から減っていない項目には「前回から手つかず」と書く**
5. 同じ出力パスに上書き

再スキャンでは新しいものが必ず出てくる（前の大物に隠れていたもの、更新で増えた残骸）。
前回のリストをなぞるだけで終わらせない。

## やらないこと

- 削除・移動の実行。提案までで止める
- 「Xデーモンを止めれば速い」のような、頼まれていない周辺提案
- 危険なコマンドを注記なしで置くこと。`sudo rm -rf` を載せるときは
  **消してはいけない側（KEEP）も必ず併記する**
